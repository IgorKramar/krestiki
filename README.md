# Крестики-нолики онлайн

Двое играют в реальном времени, статистика и таблица лидеров сохраняются. Ноль зависимостей: Node ≥ 24.2 (`node:sqlite`, `node:test`, `import.meta.main`).

```sh
npm start        # http://localhost:3000   (PORT, DB_PATH переопределяются через env)
npm test
```

Сыграть с самим собой: второе окно в режиме инкогнито (имя привязано к cookie браузера).

## Как устроено

| Файл | Что делает |
|---|---|
| `game.js` | чистая логика: проверка хода, победитель, ничья |
| `server.js` | HTTP-API, Server-Sent Events, SQLite (`krestiki.db`), присутствие игроков |
| `public/index.html` | весь фронт: вход, лобби, доска, статистика |
| `test.js` | логика партии + сквозной HTTP/SSE-сценарий на двух игроках |

**Согласованность.** Сервер — единственный источник истины. У партии есть `version`; ход отправляется вместе с версией, которую видел клиент. Версия не совпала → `409` и актуальная доска в ответе. Клиент никогда не рисует ход сам: только то, что вернул или прислал сервер. Оба игрока получают одни и те же события в одном порядке.

**Реальное время.** `GET /api/events` — SSE-поток на пользователя. События: `hello` (полный снимок при подключении и после каждого переподключения), `game`, `lobby`, `stats`. Ходы и действия — обычные `POST`.

**Присутствие.** Онлайн = есть открытый SSE-поток. Если соперник пропал больше чем на 30 с, второй может засчитать себе победу. «Ожидающая» игра ушедшего игрока удаляется через 5 с (грейс на перезагрузку страницы).

## API

| Метод | Путь | Что |
|---|---|---|
| POST | `/api/login` `{name}` | имя свободно → новый пользователь + cookie; занято → 409 |
| POST | `/api/logout` | |
| GET | `/api/me` | |
| GET | `/api/events` | SSE |
| GET | `/api/lobby` | ожидающие игры, счётчики |
| GET | `/api/dashboard` | моя статистика, лидеры, последние партии |
| POST | `/api/games` | создать ожидающую игру (идемпотентно) |
| GET | `/api/games/:id` | |
| POST | `/api/games/:id/join` | |
| POST | `/api/games/:id/move` `{cell 0–8, version}` | |
| POST | `/api/games/:id/resign` · `/cancel` · `/claim` · `/rematch` | реванш один на двоих, стороны меняются |

## Что намеренно не сделано

- Пароли: имя закрепляется за браузером через cookie; потерял cookie — имя потеряно. Добавить, когда понадобится вход с нескольких устройств.
- Один процесс: SQLite синхронный, гонок между ходами нет по построению. Для нескольких инстансов нужен общий pub/sub для SSE.
- Таймер на ход: сейчас только «соперник пропал на 30 с».
